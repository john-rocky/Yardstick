Unified memory on Apple Silicon means the CPU and GPU share one physical pool of memory, so a model's weights do not have to be copied into a separate video memory before the GPU can read them. On a phone, the same idea applies to the system-on-chip: the CPU, GPU and any neural accelerator address the same DRAM, and the practical limit for a local language model is how much of that DRAM the operating system will let one process keep resident, together with the memory bandwidth the chip can sustain while it decodes one token at a time.
