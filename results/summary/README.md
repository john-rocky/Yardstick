# results/summary — derived, machine-readable accumulation

Generated by `scripts/build_summary.py` from `results/quality/` and the
committed `app-path*/` device records. Raw logs stay canonical; this layer is
for querying, regression tracking, and leaderboard export — regenerate any
time with `python3 scripts/build_summary.py`.

- `quality.csv` — 31 GSM8K report rows (all historical schema variants normalized)
- `device-runs.csv` — 398 per-run device records (speed / memory / energy cells)

Engine version is absent from pre-v1 rows (see the gap audit); new writers must
emit `schema/result.v1.json` so the column can be joined from data, not prose.
